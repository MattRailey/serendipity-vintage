# Listing output format

For each piece, reply with this structure. Keep the Etsy and Vinted parts separate so each can be copied straight into its form.

---
**[Piece code, if given] — short name**

**Research**
- Era: 1970s (fairly sure). Reasons: union label style, 65/35 poly-cotton care tag, Talon zipper.
- Maker: brand and a one-line history, if known.
- What would confirm it: …

**Price:** suggested $__ · range $__–$__ · Vinted $__
Comps: 2–4 comparable pieces with price, where, and sold or asking.

**ETSY**
- **Title** (under 15 words): …
- **Tags** (13, each 20 characters or fewer): tag, tag, tag, …
- **Category:** Clothing › Women's Clothing › Dresses
- **Attributes:** When made · Primary color · Secondary color · Material · Size (the *modern* size from the measurements) · Style · Occasion · Sleeve length · Neckline · anything else Etsy offers for the category
- **Description:**
  - An opening 1–2 sentences that naturally restate era, maker, fabric, style and fit.
  - Measurements (laid flat, inches), tag size, and estimated modern size.
  - Details: label, fabric content, closures, lining, where made.
  - Condition: a grade, then each flaw with its location and photo number.
  - An optional closing shop line.

**VINTED**
- **Title:** Brand + item + key detail + size
- **Category / Brand / Size / Color / Material**
- **Condition:** exactly one of *New with tags*, *New without tags*, *Very good*, *Good*, *Satisfactory*
- **Description:** a shorter version of the Etsy text, ending with 3–5 hashtags.

**Questions:** anything missing or uncertain. If nothing is missing, leave this out.
---

When Sarah asks for "just the Etsy" or "just the title and tags," give only that.
